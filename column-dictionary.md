# CSV Column Dictionary

| Column | Type | Meaning |
|---|---|---|
| batch | string | Exact student batch identifier |
| day | string | Weekday |
| start_time | HH:MM | Class start |
| end_time | HH:MM | Class end |
| subject | string | Subject title |
| room | string | Classroom identifier |
| instructor | string | Instructor name |

Validate required columns, non-empty values and 24-hour time format. Never fill missing values by guessing.
